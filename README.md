# ONCOPOINT — Доступная медицина для каждого

**ONCOPOINT** — цифровая медицинская платформа для повышения доступности профилактических обследований и раннего выявления онкологических заболеваний среди жителей отдалённых сёл Казахстана.

## 1. О проекте

Проект направлен на решение проблемы доступности медицинской помощи в сельских районах. Платформа объединяет жителей, медицинских работников и мобильные медицинские бригады в единую цифровую систему.

Основная цель — помочь жителям своевременно проходить обследования, получать консультации специалистов и отслеживать состояние своего здоровья.

## 2. Основные возможности

### Dashboard — Главная панель
- Общая статистика проекта.
- Количество мобильных бригад.
- Количество медицинских точек.
- Контроль охвата населения.
- Отслеживание бюджета проекта.

### Mobile Clinic — Мобильные клиники
- Отображение четырёх мобильных бригад.
- Контроль маршрутов движения.
- Отображение 20 медицинских точек.
- Распределение 80 сёл между бригадами.
- Просмотр следующей остановки каждой бригады.

### Medical Card — Электронная медицинская карта
- Просмотр текущих медицинских показателей.
- История предыдущих обследований.
- Сравнение результатов за разные периоды.
- Графики динамики показателей.
- История посещений врачей.

### TeleMed — Онлайн-консультации
Концепция дистанционных консультаций специалистов и получения медицинских рекомендаций.

### FastLab — Лабораторные анализы
- Отслеживание статуса анализов.
- Контроль доставки биоматериалов.
- Просмотр результатов обследований.
- Целевой срок получения результатов — 1–2 дня.

### EarlyCheck — Ранняя диагностика
- Профилактические обследования.
- Запись на медицинские осмотры.
- Напоминания о профилактике.
- Направление к профильным специалистам.

## 3. Распределение мобильных бригад

| Показатель | Количество |
|---|---:|
| Население области | 500 000 |
| Сельские населённые пункты | 80 |
| Мобильные бригады | 4 |
| Сёла на одну бригаду | 20 |
| Медицинские точки | 20 |
| Точки на одну бригаду | 5 |
| Целевой охват | 1 000 жителей |

Каждая мобильная бригада обслуживает отдельный сектор области.

## 4. Ограничения проекта

- Бюджет: 40 млн ₸.
- Срок реализации: 6 месяцев.
- Необходимый охват: минимум 1 000 жителей.
- Использование существующей медицинской инфраструктуры.
- Отсутствие строительства новых больниц и закупки дорогостоящего оборудования.

## 5. Запуск проекта

1. Скачайте файл `oncopoint_demo.html`.
2. Откройте его в браузере (Google Chrome, Safari или Firefox).
3. Сайт запустится локально на вашем устройстве.
4. Используйте боковое меню для перехода между разделами.
   или откройте любой online html компилятор и вставьте код проекта

## 6. Технологии

Текущий демонстрационный прототип создан с использованием:

- HTML5 — структура сайта.
- CSS3 — оформление и адаптивный дизайн.
- JavaScript — интерактивность и навигация.
- SVG — демонстрационная карта и графики.

## 7. Важное примечание

Текущая версия является демонстрационным прототипом (Frontend MVP).

Карта использует условные координаты, медицинские показатели и записи являются демонстрационными. Данные не передаются в реальную медицинскую систему.

Для полноценного запуска необходимо подключить серверную часть, базу данных, защищённую авторизацию, реальные геоданные, GPS и интеграцию с медицинскими учреждениями.

**ONCOPOINT — медицинская помощь должна быть доступна каждому, независимо от расстояния.**
